# 📂 Repositorio de Códigos y Ejercicios Académicos

Este repositorio contiene varias **carpetas organizadas por materia**, las cuales incluyen **códigos, prácticas y ejercicios** desarrollados durante distintas asignaturas de la carrera.

Algunas carpetas pertenecen a **la misma materia**, mientras que otras corresponden a **materias independientes**, cada una con su propio enfoque y tecnologías.
